# Kiteline project

Kiteline is a desktop app for working with Claude on a project through a ticket list, an Inbox of cards and chat tabs.
This folder is a Kiteline project: open it in Kiteline rather than in plain Claude Code, since its tabs get the rules,
the tickets and the project's settings that a plain session misses.

- How Claude works in any Kiteline project: `~/.config/agent-inbox-ui/OPERATING.md`.
- This project (what it is, the role, the checks): `.agent-inbox/PROJECT.md`.
- How it works: `DESIGN.md`; settled decisions: `DECISIONS.md`.
