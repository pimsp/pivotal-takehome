# The take-home

What this adds: what the take-home consists of, for the owner. Provisional until the task text arrives.

- The invitation (`assignment.md`) gives the time allowed, the deadline and what is needed to run the test.
- The task text, the work and how it is submitted are added here when the take-home starts.
- Jobs that need a GPU can run on a rented Runpod pod. Their results come back into the project, and the pod is
  deleted afterwards. The runbook sits with the GPU scripts.
